# TAPtoTEN 음악 청취 데모

사용자 요청: TAPtoPICK처럼 대기/게임 음악을 구분하되 같은 음악은 사용하지 않고, 발랄하고 귀여운 퍼즐 게임과 탭댄스 분위기로 두 곡을 시청한다.

- `01-lobby-little-tap.mp3`: 112 BPM, 약 36초. 맑은 말렛 계열 선율, 피아노 화음, 베이스와 가벼운 탭 리듬.
- `02-game-number-shuffle.mp3`: 118 BPM, 약 35초. 짧은 피아노 선율과 조금 더 촘촘한 탭 리듬.

외부 음원/샘플을 복사하지 않고 `make-demos.mjs`에서 음표와 합성 파형을 구성했다. 전문 음악 생성 모델이나 실제 악기 녹음은 아니다. WAV를 44.1kHz 스테레오로 합성하고 FFmpeg로 192kbps MP3 인코딩했다. 생성 단계 피크 0.78, 두 MP3의 인코딩·길이를 확인했다. 음악적 선호는 사용자 청취로 확인해야 한다.

이는 끝맺음과 잔향이 있는 청취 초안이며 완성된 무봉제 루프가 아니다. 게임에 연결하지 않았다. 적용 결정 후 루프 경계, 음량, 장면 전환과 영상 재생 중 정지 동작을 별도로 구현·검증한다. 이전 연구자료는 수정하지 않았다.

재생성 시 기존 초안을 덮어쓰지 말고 새 출력 폴더를 사용한다: `node docs/music-demos/2026-09-14/make-demos.mjs <출력폴더>`.

## 게임용 템포 수정안

사용자는 대기용을 좋게 평가하고 게임용만 조금 빠르게 요청했다. 대기용과 기존 게임용 파일은 보존하고 `02-game-number-shuffle-124bpm.mp3`를 추가했다. 118→124 BPM(약 5.1% 증가), 약 33초다. 원본 생성 스크립트의 WAV에 FFmpeg `atempo=1.0508474576271187`을 적용하여 음높이와 편곡을 유지하고 192kbps MP3로 인코딩했다. 게임에는 아직 적용하지 않았다.

## 승인 이후 적용

이후 사용자가 두 곡 적용을 승인했다. 위 설명은 청취 초안 제작 시점의 기록이다. `--loop` 옵션은 같은 음표/악기를 112/124 BPM으로 합성하고 끝의 잔향을 앞에 감아 반복용 WAV를 만든다. 승인된 빠른 버전은 루프용으로 124 BPM에서 직접 렌더링했다. 배포 MP3 및 장면 전환 검증은 [적용 연구기록](../../research/2026-09-14-scene-music/README.md)에 별도로 보존했다. 기존 청취 MP3는 덮어쓰지 않았다.
