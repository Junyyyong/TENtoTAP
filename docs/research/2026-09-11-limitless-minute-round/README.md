# LIMITLESS: 튜토리얼 이후 60초 점수 모드

## 문제와 요청

사용자는 30단계까지를 튜토리얼로 구분하고, 5·13·22·30단계 완료에는 성적과 무관하게 GREAT 영상을 요청했다. 그 이후에는 단계를 계속 올리는 대신 1분 동안 얻은 점수로 평가하도록 요청했다. 이전에 논의한 구간별 제한시간(30초·90초·120초)은 채택하지 않았다.

## 변경과 이유

- 튜토리얼 1~30단계와 기존 단계별 제한시간은 유지한다. 지정한 네 지점에는 GREAT를 재생한다. 표시 제목은 BONUS BREAK 대신 STAGE CLEARED다.
- 30단계 완료 영상 뒤에는 `MAKE 10 / IN 60 SECONDS` 안내가 나온다. 탭해야 본게임 시계가 시작한다.
- 본게임은 9×9 판, 0점, 60초로 새로 시작한다. 튜토리얼 점수는 합산하지 않는다. STAGE 대신 BEST를 표시한다.
- 본게임에서 판을 비우거나 가능한 조합이 없어 새 판을 배치해도 시계를 초기화하거나 전환 시간만큼 멈추지 않는다. 기존 점수 달성 시간 보상도 적용하지 않는다.
- 40·50단계 등의 영상은 없다. 본게임 종료 시 그 60초 동안 얻은 점수로 기존 등급 영상을 선택한다(0점 NOT BAD 포함).
- 최고기록은 과거 튜토리얼 누적 점수와 별도 저장한다. 본게임 Retry는 본게임을 재시작한다. 메뉴에서 새로 시작할 때는 테스트 설정에 따라 튜토리얼 1단계부터 시작한다.

9×9 본게임 판과 별도 최고기록은 단계 없는 점수 모드를 구현하기 위한 선택이다. 학습 효과나 적정 난이도를 사용자 실험으로 검증한 결과는 아니다. ENDLESS와 TIMELESS의 점수 규칙은 바꾸지 않았다.

## 재현과 검증

- 변경 전: 커밋 `989471e`를 `git archive`로 별도 임시 폴더에 추출하여 재현했다. 현재 작업 소스는 과거 버전으로 교체하지 않았다.
- 변경 후: `989471e` 기반 작업 트리. 이 문서를 포함한 변경 커밋으로 소스를 식별할 수 있다.
- 실제 재현 촬영일: 2026-09-11. Chrome 152.0.7977.83, 390×844 CSS px, DPR 2, 원본 **780×1688 PNG**.
- 전후 새 저장소 프로필, 동일한 제어 시계와 숫자 난수 초기값을 사용했다. 블록 색은 crypto 난수라 전후 다르며, 영상 프레임도 실제 재생 시점에 따라 다르다. 과거 의존성 전체를 복원한 것은 아니며 현재 설치된 Vite로 실행했다.
- 전후 모두 메뉴에서 시작해 실제 입력으로 30단계를 풀었다. 저장 진도 주입이나 임의의 과거 화면 생성은 하지 않았다.
- 브라우저 검증: 네 지점 GREAT, 30단계 후 0점·60초, 시작 안내 중 시계 정지, 81블록·BEST 표시, 실제 정답 득점, 시간 종료 등급, 별도 최고기록 저장, 본게임 재시작을 확인했다. 브라우저 오류 없음.
- 단위 테스트 145개 및 프로덕션 빌드 통과. 본게임 판 갱신 시 시간·점수 유지, 시간 보상 없음, 60초 종료도 단위 테스트로 검증했다.
- [검증 결과·원본 SHA-256](verification.json), [재현 스크립트](check.mjs). 확정된 원본을 보존하려면 재촬영 시 스크립트 출력 경로를 새 폴더로 변경한다.

스크린샷은 개발 동작 검증 자료다. 실기기 Safari/Android, 음향 품질, 학습 효과의 검증 자료는 아니다. 연구 스크립트는 게임 실행 코드에서 import하지 않는다.
