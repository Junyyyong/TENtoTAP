# 메인 로고 크기·원본 이미지로 꽉 채운 설치 아이콘

## 후속 조정 · 최신 후보

사용자는 직전 로고가 너무 크다며 **지금 크기의80%**와 나머지 여백 유지를 요청했다. `MAIN_LOGO_SIZE=.8`을 기존 화면별 공간 제한 **후**에 적용해 짧은 화면/태블릿도 직전 실제 크기의80%가 된다. 원본 비율·중심·기존 flex 공간과 다른 UI 위치는 그대로다. 기준390×844는 약309→247px다. 아이콘·첫 스튜디오·커버는 이번 후속에서 변경하지 않았다.

Settings의 Vibration 행·설명·지원 불가 안내문과 이벤트를 제거해 Music/Sound만 남겼다. 과거 `hapticsOn` 저장 필드는 호환성을 위해 보존하되 앱은 `feedback.setHaptics(false)`로 사용하지 않는다. Music/Sound·개인정보/라이선스 링크·진도/기록/저장 형식은 유지했다. 진동을 새로 구현하거나 권한/플러그인을 추가한 작업이 아니다.

기존 `attempt-2`에 보존한 직전 후보의8화면 측정/원본 PNG와 비교하고, 설정 변경 전은 동일한 기본 Settings를 가진 커밋`97b9b0c`를 별도 `git archive`에서 재현했다. 고정 시계·브라우저·DPR·모바일 해상도는 동일하다. 이번 Settings 검사만 의도적으로 과거 `hapticsOn:true`를 사용하고 `navigator.vibrate` 호출을 spy로 기록했다(물리 진동 시험 아님). [최신 후속 결과](size-review-complete/verification.json): 8화면에서 직전 폭/높이×80%, 중심·다른 UI·예약 공간 동일; Music/Sound 토글/저장·기록 유지; 진동 스위치0/호출0. 전체27파일249개 테스트·웹 빌드 통과. 최초 `size-review`는 검사 스크립트가 존재하지 않는 `feedback.refuse()`를 호출해 실패했으며, 실제 메서드`reject()`로 수정 후 새 폴더에서 통과했다. 실패 캡처/결과도 보존한다.

`size-review-final`도 모든 검사에 통과했으나 Settings 캡처가 화면 전환의 페이드 중간에 촬영되었다. 촬영 스크립트에서 rAF 이후 시작된 유한 CSS 애니메이션까지 완료한 `size-review-complete`로 재촬영·재검증했다. 게임 소스는 재촬영 과정에서 변경하지 않았으며 이전 캡처도 보존한다.

실기기/AAB/push는 수행하지 않았다. 아래는 직전 확대·아이콘 후보의 근거와 당시 검증이며 덮어쓰지 않았다.

## 요청과 결정

2026-10-02 사용자는 현재 TAPtoTALK을 읽기만 참고해 TEN 메인 로고의 존재감을 키우고, 투명 여백까지 고려하도록 요청했다. 후속 답변에서 **가로/세로 치수의 정확한 일치보다 비슷한 느낌**이 목적이며, **잘림과 버튼 겹침은 절대 허용하지 않는다**고 정리했다. 로고 위치·나머지 UI·첫 스튜디오·커버는 변경하지 않는다.

설치 아이콘은 원본 사각형 이미지가 원형 안을 꽉 채우고 모서리가 잘리는 구도를 원했다. 비슷한 주황 바탕을 덧대고 이미지를 작게 넣었던 이전 방식은 제거한다.

## 변경

- TEN의 원본 `public/cover-logo.svg`와 비율을 유지한다. 원래 flex 공간과 로고 중심은 그대로이며 **그려지는 로고만 동일 배율로 확대**한다. 메뉴·Settings 위치/크기/서체/색은 변경하지 않는다.
- TALK의 현재 PNG와 CSS 가로/세로 한도로 실제 보이는 폭을 계산해 기준으로 삼는다. 두 로고를 alpha 0/8/32 임계값으로 검사했으며 가로 투명 여백은 없다. 파일의 CSS 최대 폭330px를 실제 폭으로 오인하지 않는다.
- 여유 있는390×844에서 실제 폭250→약309px(약24% 확대). 공간이 부족하면 기존 로고 중심부터 상단 여백·메뉴까지의 대칭 공간으로 한도를 제한한다. 예:390×640에서는148→약217px이며 TALK의262px를 억지로 맞추지 않는다. 태블릿도 같은 기준/공간 제한을 적용한다.
- Android 기존 밀도 정규화는 그대로다. 게임 규칙·저장·서명·패키지명·버전은 변경하지 않는다.
- 원본 아이콘 PNG2134×2135는 보존한다. legacy48dp는 전체 사각 이미지를 빈 테두리 없이 채우며 round는 같은 이미지에 원형 mask만 적용한다. Adaptive108dp 레이어의 **실제72dp mask 영역**도 동일한 원본 전체 사각형으로 채운다. 바깥18dp씩은 원본 가장자리 픽셀을 연장한 애니메이션 여유이며 별도의 유사색 바탕은 없다. 배경 색 리소스는 투명으로 바꾼다. 1px export 차이는 cover 리사이즈로 처리한다.
