# 대기/플레이 배경음악 분리

## 문제와 요청

사용자는 TAPtoPICK처럼 대기 화면과 게임에 서로 다른 음악을 요청했다. 기존 게임의 음원 재사용은 원하지 않았고, 귀엽고 발랄한 퍼즐 게임에 탭댄스 느낌을 원했다. 두 합성음 데모 청취 후 대기용 112 BPM을 선택하고 게임용은 118→124 BPM으로 조금 빠르게 한 버전을 승인했다.

## 무엇을 왜 바꿨는가

- TAPtoPICK 로컬 저장소의 `sceneMusic.ts`, `backgroundMusic.ts`, 설정/상태 연결을 읽기 참고했다(확인 시 HEAD `09afdcba024d59811e680dc7e3a3cded964ae48b`). 해당 저장소는 수정하지 않았다. 장면별 단독 재생·자동재생 차단 대응·페이지 숨김·중단 위치 재개 구현과 그 단위 테스트를 가져와 TAPtoTEN 흐름에 연결했다.
- 대기/메뉴/모드 선택에는 112 BPM, 시작 안내와 실제 플레이에는 124 BPM 음악을 사용한다. 스튜디오 로고와 커버는 무음이며 메뉴부터 재생을 시도한다.
- 일시정지, GREAT 영상, 종료 결과 영상/결과창은 무음이다. 영상의 기존 소리는 그대로 유지한다. 복귀하면 해당 장면 음악을 재개한다. 두 배경음악은 동시에 재생하지 않는다.
- 자동재생 허용 환경은 메뉴 진입 시 시작한다. 차단되면 `Tap for music`을 표시하고 실제 터치/클릭/키 입력으로 재시도한다. 자동재생을 강제로 허용하는 설정은 제품 코드에 없다.
- Settings에 Music 스위치를 추가하고 별도 저장한다. Sound는 기존 효과음/영상 소리를 제어한다. 기존 저장 데이터에 Music 항목이 없으면 켜짐으로 시작한다.
- 두 승인된 데모의 음표·악기 구성을 유지한 루프를 합성했다. 게임용은 124 BPM으로 직접 렌더링했다. 듣기용 데모의 끝 여백/페이드 대신 16마디 경계에서 잔향을 시작 부분으로 감아 공백을 제거했다. 약 34.286초/30.968초, 44.1kHz 스테레오, 192kbps MP3다. 재생 시작은 0.35초 동안 gain 0→0.28로 올린다.
- [데모와 생성 스크립트](../../music-demos/2026-09-14/README.md)는 기록용이다. `--loop` 옵션 출력 WAV를 MP3로 변환해 `public/assets/audio/`에 넣었고, 기록 스크립트는 게임에서 import하지 않는다. 다른 게임 음원이나 외부 샘플은 사용하지 않았다.

## 재현 및 검증

- 변경 전 커밋 `e42b3bc`를 별도 임시 폴더에 git archive로 추출했다. 현재 파일을 과거 소스로 교체하지 않았다. 변경 후는 이 커밋 기반 작업 트리이며 이 기록을 포함하는 커밋으로 식별한다.
- 실제 촬영일 2026-09-14, Chrome 152.0.7977.83, 390×844 CSS px / DPR 2 = **780×1688 PNG**. 전후 동일한 새 프로필·제어 시계·숫자 난수 초기값을 사용했다. 블록 색의 crypto 난수와 실제 영상 프레임은 다를 수 있다. 당시 의존성 전체 복원 대신 현재 설치된 Vite를 사용했다.
- 단위 테스트 **172개 통과**, TypeScript 및 프로덕션 빌드 통과. 차단된 자동재생, 늦은 비동기 완료, 로딩 실패 재시도, 페이지 숨김·복귀, 장면 배타성, 설정 마이그레이션/독립 음소거를 검증했다.
- 실제 Chrome에서 MP3를 디코딩해 loop source의 지속시간/활성 상태를 관찰했다. 메뉴→선택→게임 안내→플레이→일시정지→복귀, 실제 5개 튜토리얼 풀이→GREAT→6단계→시간 종료→메뉴를 진행했다. BGM 중복 없음, 영상/결과 중 BGM 정지, 메뉴곡 복귀, Music 끄기 후 새로고침 유지 확인. 실행 중 페이지 오류 없음.
- [검증 스크립트](check.mjs), [검증 결과 및 PNG SHA-256](verification.json). 확정된 전후 자료를 재촬영할 때는 새 출력 폴더를 사용해야 한다.

## 제한

자동화는 실제 Web Audio 상태를 확인하지만 청취 품질이나 탭댄스 악기 사실성을 평가하지 않는다. 데모에 대한 사용자 피드백과 최종 루프의 실기기 음량/반복 청취 평가는 구분한다. iPhone Safari/Android 실기기 오디오 및 학습 효과는 이번에 검증하지 않았다. 게임 점수·튜토리얼·영상 일정은 변경하지 않았다. 기존 연구 원본은 보존했다.
