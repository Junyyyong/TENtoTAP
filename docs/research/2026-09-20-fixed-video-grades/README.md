# 튜토리얼 고정 영상 순서와 TIMELESS 시간 등급

## 요청·결정

사용자는 튜토리얼 다섯 학습 구간의 완료 영상이 단계적으로 좋아지도록 요청했다. TIMELESS 최고 등급은 전체 클리어 1분 20초로 낮추고 다른 구간도 5분까지 재조정하도록 요청했다. “최대 5분”의 의미를 확인한 결과 게임 제한시간을 두지 않고 5분 초과 클리어를 GOOD TRY로 하는 안을 사용자가 선택했다. 1분 미만 클리어가 실제로 가능한지에 대한 사용자 실험은 이번 작업에서 수행하지 않았다.

## 변경

| LIMITLESS 튜토리얼 완료 단계 | 영상 |
|---|---|
| 5 | GOOD TRY |
| 13 | GREAT |
| 22 | AMAZING |
| 29 | UNBELIEVABLE |
| 30 | OH MY GOD |

기존 5·13·22·30 완료의 랜덤 분배를 고정 단계 매핑으로 바꾸고 29 완료 영상을 추가했다. 29 영상 뒤 30의 CLEAR ALL BLOCKS 안내, 30 영상 뒤 60초 본게임 흐름은 유지한다. 각 영상은 누적 점수와 무관하다. 재시도해도 해당 단계 영상이 동일하다. 튜토리얼 시간 초과 결과는 기존 점수 등급을 유지한다.

| TIMELESS 전체 클리어 시간 | 영상 |
|---|---|
| 1분 20초 이하 | OH MY GOD |
| 1분 20초 초과~2분 이하 | UNBELIEVABLE |
| 2분 초과~3분 이하 | AMAZING |
| 3분 초과~5분 이하 | GREAT |
| 5분 초과 | GOOD TRY |

미완료는 기존대로 점수가 있으면 GOOD TRY, 0점이면 NOT BAD다. 정확히 경계 시간에 끝나면 상위 등급을 받는다. 시간제한은 추가하지 않았다. 블록 수/합계별 점수 계산, LIMITLESS 본게임/ENDLESS의 점수 등급, ENDLESS의 시작 안내만 있는 구성은 변경하지 않았다.
