# 기다림 없는 산식 결과 유지

## 요청·변경 이유

사용자는 1.5초 강제 확인이 게임의 속도감을 해친다고 평가했다. 정답뿐 아니라 오답도 아래 산식만 남기고, 다음 숫자를 누르면 새 산식으로 교체하는 방식으로 변경을 요청했다. 이 피드백은 사용자 한 명의 개발 중 의견이며 사용성 실험 결과는 아니다.

## 변경과 결과

- 정답은 즉시 기존 제거·점수·단계 진행을 처리한다. 오답은 선택을 해제하고 즉시 재입력을 받는다.
- 산식과 실제 합계를 유지한다. 정답은 기존 정답 색, 오답은 빨간 결과·테두리로 구분한다. 자동 빈 선택 알림이나 판 교체로 결과를 지우지 않는다.
- 다음 비어 있지 않은 선택(새 숫자 입력)이 들어오면 결과 상태를 해제하고 새 산식으로 바꾼다. 2~5개 조합에 공통 적용한다.
- 산식 확인 전용 1.5초 타이머·상태·입력/아이템 잠금·게임 시계 정지를 제거했다. 기존 단계 전환·안내·영상에 필요한 정지는 유지한다. 메뉴/새 화면 진입 시 결과는 초기화한다.
- 영상 선택·재생 보강과 NOT BAD 파일은 바꾸지 않았다.

촬영일 2026-09-20. Chrome, 390×844 CSS px / DPR 2의 **780×1688 PNG**. 같은 제어 시계·숫자 난수·음악/효과음 음소거 새 프로필 조건. 블록 색 crypto 난수는 서로 다를 수 있다. 당시 의존성 전체 대신 현재 Vite를 사용했다.

실제 모바일 입력으로 오답 후 시계 진행, 다음 입력 즉시 반응·산식 교체, 정답 즉시 다음 단계, 판 교체 및 2초 이상 경과 후에도 결과 유지, 다음 숫자의 새 산식 교체를 확인했다. 단위 테스트 177개 및 프로덕션 빌드 통과. 제거된 확인 전용 상태 테스트 1개는 새 규칙에 맞춰 삭제했다. 새 변경의 브라우저 검증은 2블록 실제 입력이며 3~5개는 동일 공통 표시 경로를 사용한다.

[검증 스크립트](check.mjs), [조건·결과·원본 SHA-256](verification.json). 확정 촬영본은 재촬영 시 새 폴더를 사용해 보존한다. 기존 1.5초 버전의 연구 원본은 덮어쓰지 않았다.
