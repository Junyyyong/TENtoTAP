# 테스트 기간: LIMITLESS를 1단계부터 시작

## 요청 / 변경 이유

사용자는 출시 전 반복 테스트를 위해 저장 단계 이어하기를 잠시 사용하지 않고 처음부터 시작하도록 요청했다.

## 변경

- 모드 메뉴에서 START를 누르면 저장값과 관계없이 1단계부터 시작한다. 시작 화면의 STAGE와 시간 설명도 1단계 기준이다.
- 테스트 중에는 진행 단계 저장을 갱신하지 않는다. 기존 저장 진도와 최고점수를 삭제하지 않는다. 최고점수는 기존처럼 기록한다.
- 한 번 시작한 게임에서는 다음 단계로 정상 진행한다. 시간 초과 후 Retry는 같은 단계에서 재시도한다. 메뉴로 나갔다 다시 시작하거나 새로고침하면 1단계다.
- `src/content/testSettings.ts`의 `RESUME_LEARNING_PROGRESS = false`로 정책을 분리했다. 출시 때 true로 변경하면 기존 저장 진도 읽기/쓰기를 다시 사용할 수 있다. 이 변경은 로컬 개발만이 아니라 배포된 앱에도 적용되는 정책이다.
- 다른 모드 및 튜토리얼 규칙·영상·시간은 변경하지 않았다.

## 검증

- 단위 테스트 143개 및 프로덕션 빌드 통과. 여러 저장 단계가 있어도 시작 단계가 1인지 검사했다.
- 모바일 Chrome에서 저장 단계 14를 무시한 시작, 2단계 정상 도달, 저장 진도 비갱신, 시간 초과 후 2단계 Retry, 새로고침 후 1단계 시작을 확인했다.
- 실제 기기의 장시간 플레이나 출시 후 저장 정책을 검증한 것은 아니다. [verification.json](verification.json)에 원본 해시·촬영 시각·브라우저 버전을 기록했다. [check.mjs](check.mjs)는 게임에서 import하지 않는 연구용 스크립트이며 후속 촬영은 새 경로를 사용한다.
