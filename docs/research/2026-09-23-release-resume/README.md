# 출시용 LIMITLESS 진도 이어하기

## 요청과 변경

사용자는 테스트용 1단계 강제 시작을 해제하고, 튜토리얼 중 종료해도 도달한 단계부터 이어 하도록 요청했다. 로고·커버·메뉴·모드 선택 화면은 그대로 유지한다.

- 기존 저장 진도를 읽는 출시 설정을 활성화했다. 성공한 선택을 처리하면서 다음 단계 번호를 즉시 localStorage에 저장하므로 앱 종료 이벤트에 의존하지 않는다.
- 예: 9단계를 완료해 10단계에 도달한 뒤 새로고침/종료하면 다음 LIMITLESS START는 10단계다. 숫자 배치·단계 제한시간·현재 점수는 새 게임으로 초기화된다. 정확한 판/남은 시간/부분 선택 복원이 아닌 **단계 단위 이어하기**다.
- 30단계 완료 후 본게임 전환 시 31을 완료 표식으로 저장한다. 이후 새 접속은 0점/60초 본게임을 시작하며, 선택 화면에는 존재하지 않는 STAGE 31 대신 ROUND / 60 SECONDS를 표시한다.
- 잘못된 진도는 1, 기존 31 초과 진도는 완료 표식 31로 정규화한다. 영상 일정과 점수·등급은 바꾸지 않았다.
- 같은 사이트·기기·브라우저 저장소 안에서만 유지한다. 브라우저 데이터 삭제·시크릿 창·다른 기기 간 동기화는 보장하지 않는다. 저장소 접근이 거절되면 기존의 예외 처리에 따라 플레이는 유지되지만 저장은 되지 않는다.

## 검증

- 실제 촬영일 2026-09-23. 390×844 CSS px / DPR 2 = **780×1688 PNG**. 같은 Chrome·제어 시계·숫자 난수 초기값·새 프로필에서 시작한다. 음소거 설정만 초기화하며 진도를 주입하지 않는다. 색 crypto 난수와 영상 프레임은 다를 수 있다. 과거 의존성 전체 대신 현재 Vite를 사용했다.
- 전후 모두 실제 선택으로 10단계까지 진행 후 페이지를 새로고침했다. 변경 후 10단계 재개, 이후 30단계까지 진행하고 완료 표식 31 저장, 재접속 시 새 60초 본게임과 0점 확인. 이전은 1단계부터 다시 시작하는 것을 확인했다.
- 다섯 튜토리얼 완료 영상, 29→30 안내, 30→본게임 흐름 확인. 단위 테스트 178개 및 프로덕션 빌드 통과.
- 새로고침은 종료 후 로컬 진도 재로딩을 검증하는 방식이며, 모든 모바일 운영체제의 강제 종료·저장소 삭제 시나리오를 검증한 것은 아니다. 기존 연구 원본은 보존한다.
- [재현 스크립트](check.mjs), [결과·원본 SHA-256](verification.json). 확정 원본 재촬영 시 새 폴더를 사용한다. 연구 스크립트는 게임에 import하지 않는다.
