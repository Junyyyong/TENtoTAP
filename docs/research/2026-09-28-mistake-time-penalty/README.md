# LIMITLESS 본게임 오답 −1초

## 문제/요청

사용자는 무작위로 블록을 계속 누르는 플레이를 줄이기 위해 시간 벌점을 제안했다. 논의 후 **LIMITLESS 본게임에서 오답마다 1초 차감**, 타이머 옆에 빨간 **−1**을 약 **0.5초** 표시하는 방식으로 확정했다. 튜토리얼과 TIMELESS·ENDLESS는 제외하며 게임을 멈추지 않는다.

## 변경과 이유

- 기존 보드의 오답 확정 이벤트에서만 `penalizeMistake`를 호출한다. 2~5개 블록의 합이 10을 넘거나 5개를 골랐는데 10이 아닌 경우, 해당 선택 한 번에 1000ms를 차감한다.
- 미완성 조합·단일 블록 선택·선택 해제·제스처 취소는 벌점이 아니다. 한 드래그 안에서 오답 확정 후 더 움직여도 추가로 차감하지 않는다.
- 본게임(`timeAttack`의 `scoreAttack`)만 적용한다. 1~30 튜토리얼, TIMELESS, ENDLESS와 이전 타임어택 레벨 구현에는 적용하지 않는다.
- 남은 시간만 바꾼다. 점수·판·실제 경과 시간·블록 추가 시계는 바꾸지 않으며 입력 지연을 넣지 않는다. 오답 산식은 기존처럼 다음 숫자 입력까지 남는다.
- 타이머 오른쪽에 빨간 `−1`을 절대 위치로 배치하여 숫자나 판이 밀리지 않게 했다. 500ms 후 사라지고, 연속 오답은 각각 1초 차감하면서 표시 시간을 다시 시작한다. 동작 줄이기 설정에서는 이동 애니메이션 없이 표시한다.
- 1초 미만이 남았을 때 틀리면 0에서 멈추고 기존 TIME OUT·결과 영상 흐름으로 즉시 진행한다. 메뉴로 나가거나 새 게임을 시작할 때 표시를 정리한다.

이 변경이 무작위 입력을 실제로 얼마나 줄이는지는 사용자 실험으로 확인하지 않았다. 여기서는 구현 동작만 검증했다.

## 검증과 한계

- 단위 테스트 **217개 통과**: 저장 보강까지의 202개 + 벌점 15개. 정확한 1000ms 차감, 연속 오답, 즉시 정답 입력, 0초 하한, 종료 상태, 튜토리얼 1~30·다른 모드·전환 중 면제를 검사했다. 프로덕션 빌드 통과.
- 브라우저: 2·3·4·5개 오답, 미완성·해제·취소, 표시 중 정답, 연속 오답과 표시 재시작, 한 드래그 한 번 차감, 1초 미만 TIME OUT을 검사한다.
- 튜토리얼 다섯 구간과 TIMELESS·ENDLESS 면제, 동작 줄이기 설정, 320/375/390/430px에서 타이머·점수와 표시의 겹침 여부, 메뉴 이동 시 표시 정리, 이전과 같은 390px 판 위치/크기를 검사한다. 실행 결과는 [verification.json](verification.json)의 checks/errors가 근거다.
- Android 실기기의 체감 성능·터치 특성은 이번 브라우저 검증으로 입증하지 않는다. 기존 저장 안정화 변경과 연구 원본은 보존했다. 점수·영상 등급은 바꾸지 않았다.

[재현 스크립트](check.mjs), [검증 결과·소스/PNG SHA-256](verification.json). 재촬영은 새 `CAPTURE_OUT`을 사용한다. `PLAYWRIGHT_MODULE`과 `CHROME_PATH`로 도구 위치를 지정할 수 있다. 연구 스크립트는 게임에 import하지 않는다.
