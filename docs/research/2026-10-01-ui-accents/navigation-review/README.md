# 원형 회색 탐색 버튼·리액션 컬러 확인

2026-10-01의 강조색 복원에 대한 후속 요청이다. 사용자는 TAPtoTEST 스크린샷처럼 뒤로가기·일시정지를 회색 원형으로 맞추고, OH MY GOD 등의 리액션이 원래 컬러인지 확인한 뒤 전체 화면을 한눈에 비교할 수 있게 정리하도록 요청했다.

## 변경과 보존

- `src/ui/styles/game.css`의 공통 `.icon-btn`만 원형 `border-radius: 50%`, 아이콘 `#363c46`, 연회색 면 `#f5f6f8`, 테두리 `#cdd2da`, 그림자 없음으로 맞췄다. TAPtoTEST의 `talk.css`와 `neutralUi.css`, `tokens.css`를 읽기 참고했다. 다른 게임은 수정하지 않았다.
- 크기와 위치는 TAPtoTEN의 기존 값(기본 44×44 CSS px와 기존 작은 웹 화면 규칙)을 그대로 썼다. TAPtoTEST의 40px까지 복사해 TEN의 비율을 바꾸지는 않았다. 터치 영역이나 SVG 글리프 크기도 바꾸지 않았다.
- 눌림 `#dce1e8`, 마우스 올림 `#edf0f4`으로 중립적인 상태 구분을 적용했다. 게임의 컬러 힌트·START·제목·Settings·기록·게이지·스위치는 유지했다.
- 리액션은 수정 전부터 원래 컬러였으며 **변경하지 않았다**. 여섯 등급 모두 금색 `#ffb500`, 주황 `#d43600` 그림자, 짙은 테두리 `3px #2a0a06`이다. 길이에 따른 자동 글자 맞춤·서체·입체 효과도 그대로다.
- TypeScript·프레임·게임 규칙·저장·이미지·음악·영상 파일은 수정하지 않았다. 이번 실행 소스 변경은 `game.css`뿐이다. 회귀 테스트 한 개와 별도 연구/갤러리만 추가했다.

## 캡처와 검증

수정 직전 소스를 `before-source-overlay.tar.gz`로 보존했다. SHA-256은 `ee792ae3c98d1af93a1fe3077e624caa1efb611018e051355589bc9921458f87`이다. 기준 커밋 `cae2e49b5af230a95b2f1890daf01b47b321b621` (2026-09-29 23:22:05 +09:00)을 `git archive`로 별도 임시 폴더에 추출하고 스냅샷을 그 폴더에만 적용해 ‘전’ 화면을 재현했다. 미커밋 승인 작업을 포함한 재현이며 순수 커밋 화면이나 출시 AAB 화면이 아니다. 현재 작업 파일은 과거 버전으로 교체하지 않았다.

실제 촬영일은 **2026-10-01**, 같은 Chrome/macOS, 동일 언어 `en-US`·시간대 `Asia/Seoul`·비교 시계 `2026-10-01T00:00:00Z`·퍼즐/색 시드 `20261001`·별도 검사 저장소로 촬영했다. **390×844 CSS px / DPR 2 / 780×1688 PNG**로 통일했고 유한 애니메이션 완료/반복 애니메이션 정지 조건을 맞췄다.

- 메인·각 START/게임·일시정지·결과·Settings off/on·여섯 리액션: **17개 화면, 전후 34장**.
- 1,469개 표시 요소의 전후 서체·크기·굵기·행간 및 좌표를 대조했다. 좌표 비교 오차 한계는 0.1 CSS px, 실제 최대 차이는 0.006043 CSS px였다. 변경은 탐색 버튼의 형태·색/상태 표현으로 제한됐으며 다른 요소의 계산된 색·그라데이션·그림자도 유지됐다.
- 27개의 원형 탐색 버튼 기본 상태를 검사했다. 실제 브라우저 터치 입력으로 Settings/각 START/게임 뒤로가기, 각 모드의 일시정지·재개를 전후 18회 검사했다. 여섯 리액션의 전후 12회 검사에서 원래 색/그림자/테두리와 화면 폭 안의 배치를 확인했다.
- 비교 페이지의 17개 화면 구역, 17개 최신 썸네일, 34개 전후 이미지 모두를 브라우저에서 불러왔다. 51개 이미지가 모두 780×1688 원본으로 로드됐고, 내부 이동 링크 오류와 가로 넘침은 없었다.
- `npm test`: **25개 파일 / 240개 테스트 통과**. `npm run build`와 `git diff --check` 통과.
- 변경하지 않은 실행 소스/에셋 116개 해시, 계산된 스타일, PNG 원본 해시는 검증 JSON에 보관했다.

결과와 리액션은 실제 컴포넌트로 만든 **자동 검사 fixture**다. 실사용 점수나 실험 참가자의 결과가 아니다. 리액션 영상은 글자 색 비교를 위해 검사 프로필에서만 숨겼으며 실제 앱 영상 재생 코드·파일은 그대로다. 이 검사는 영상 디코딩·음향·실제 Galaxy/WebView 실행을 검증하지 않는다.

첫 `final/` 시도는 모바일 탭 뒤 남은 `:active`의 진한 눌림 면색을 기본 면색으로 비교해 검사 도구가 중단됐다. 기본 상태 촬영 전에 상단 비동작 영역을 터치하도록 검사 조건을 맞췄다. 두 번째 `final-verified/` 시도는 SVG 하위 요소의 사용하지 않는 `border-color: currentColor` 기본값까지 변경 불가로 비교해 중단됐다. 실제 테두리가 없는 하위 요소(두께 0, 스타일 none)에 한해서 해당 기본값을 아이콘색 변경으로 허용하도록 검사 도구를 수정했다. 버튼에 그려지는 실제 테두리는 계속 엄격하게 검사한다. 둘 다 게임 오류가 아닌 검사 조건 오류다. 실패 자료를 덮어쓰지 않고 보존한 뒤 새 `verified/` 폴더에서 전체 검증과 비교 페이지 확인을 통과했다.

연구 자료·검사 스크립트는 게임에서 import하지 않는다. **AAB 생성·버전 변경·commit/push·스토어 제출은 하지 않았다.** 실행 재현은 `PLAYWRIGHT_MODULE`과 새 `CAPTURE_OUT`을 지정해 `node docs/research/2026-10-01-ui-accents/navigation-review/check.mjs`로 할 수 있다.
