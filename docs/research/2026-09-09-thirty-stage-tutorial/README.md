# 30단계 튜토리얼 · 전체 조합 연습

## 문제와 요청

사용자는 세·네·다섯 블록으로 10을 만드는 모든 조합을 각각 연습하고, 각 묶음의 첫 두 판에서만 정답을 은은하게 알려주도록 요청했다. 30단계에서 판 전체 비우기를 연습한 뒤 일반 진행으로 연결하고 영상 구간도 학습 묶음에 맞추도록 요청했다.

## 변경 내용과 이유

| 단계 | 목표 | 정답 안내 반짝임 | 마지막 단계 후 영상 |
|---|---|---|---|
| 1–5 | 두 숫자 조합 5가지 | 1·2 | 5 |
| 6–13 | 세 숫자 조합 8가지 | 6·7 | 13 |
| 14–22 | 네 숫자 조합 9가지 | 14·15 | 22 |
| 23–29 | 다섯 숫자 조합 7가지 | 23·24 | 없음 |
| 30 | Clear all blocks. | 없음 | 30 |
| 31 이후 | 기존 전체 판 비우기·확장 | 없음 | 40·50·60… |

순서만 다른 조합을 중복으로 세지 않고 양의 정수 1–9의 비내림차순 조합을 생성한다. 게임 중 안내는 `Use 3 blocks to make 10.` 등으로 표시한다. 각 묶음의 두 번째 판 이후에도 문구는 유지하고 세 번째 판부터 정답 반짝임만 없어진다.

1–29단계는 안내한 개수의 유일한 정답 조합 하나를 찾으면 완료한다. 3×3의 방해 숫자는 9를 사용한다. 9와 최소 두 양수를 합치면 10을 초과하므로 요구 개수에 맞는 다른 답이 생기지 않는다. 일부 판에는 1+9 같은 더 짧은 합계 10이 있지만 이 연습에서는 정답으로 인정하지 않고 필요한 개수를 다시 안내한다. 이는 모든 조합을 다루기 위해 사용자에게 설명하고 합의한 규칙이다.

30단계는 합계 10인 세 묶음으로 구성한 3×3 판이다. 한 조합을 맞춰도 나머지 블록을 유지하며 전체를 비워야 완료한다. 31단계부터 기존 생성 방식으로 진행하고 3×3부터 크기별 12단계를 거쳐 103단계에 9×9에 도달한다.

숫자 위치 섞기, 색 중복/인접 방지, 1–5단계 각 15초·이후 각 60초, 영상 중 시계 정지와 터치로 이어하기는 유지한다. 기존 저장 진도는 초기화하지 않는다. 따라서 기존 사용자는 같은 단계 번호의 새 내용을 만나며, 이미 30단계를 넘었다면 튜토리얼을 자동 재시작하지 않는다.

## 검증과 한계

- 단위 테스트 140개 및 빌드 통과. 조합 수, 요구 개수에 맞는 버튼 기준 유일 정답, 위치 섞기, 1–29단계 완료, 30단계 여러 번 클리어, 40·50·60 영상 일정, 반짝임 일정, 일반 확장 판을 검사했다.
- 모바일 Chrome에서 1→31단계를 실제 터치로 진행했다. 각 단계 안내와 반짝이는 블록 수, 잘못된 개수의 합계 10 거절, 영상이 5·13·22·30 뒤에만 표시되는지 및 영상 중 시계 정지를 확인했다. 브라우저 예외 없음.
- 40단계 이후 영상은 일정 함수의 단위 테스트로 검증했으며 해당 시점까지 모바일 연속 플레이하지는 않았다. 학습 효과·사용자 반응·실기기 Safari 검증을 주장하지 않는다.
- [verification.json](verification.json)에 촬영 시각·브라우저 버전·원본 SHA-256을 보존한다. [check.mjs](check.mjs)는 게임에 import하지 않는다. 확정 원본 보존을 위해 다음 촬영은 새 경로를 사용한다.
